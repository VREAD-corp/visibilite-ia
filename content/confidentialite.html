Confidentialité

En bref : ce site ne collecte aucune donnée personnelle, ne dépose aucun cookie et n'utilise aucun traceur ni outil de mesure d'audience. Il n'y a donc pas de bandeau cookies.

Ce que fait ce site

  • Pages statiques, sans formulaire, sans compte, sans script tiers ni police externe.
  • Les documents gratuits sont téléchargés depuis GitHub Releases. Nous ne voyons qu'un compteur global de téléchargements par fichier, sans aucune information sur les personnes.

Ce que fait l'hébergeur

Le site est hébergé par GitHub, Inc. (GitHub Pages). Comme tout serveur web, GitHub peut traiter des données techniques (adresse IP, journaux de connexion) pour assurer la sécurité et le fonctionnement du service, sous sa propre responsabilité : voir la déclaration de confidentialité de GitHub.

Si vous nous écrivez via GitHub

Ouvrir un ticket (« issue ») ou réagir à un ticket nécessite un compte GitHub. Votre pseudonyme et votre message sont alors publics. Nous les utilisons uniquement pour vous répondre (base légale : intérêt légitime à traiter votre demande). Ne publiez aucune donnée personnelle, administrative ou de santé. Vous pouvez supprimer votre message à tout moment depuis GitHub.
